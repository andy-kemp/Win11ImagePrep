================================================================================
OVERVIEW
================================================================================

WinImagePrep is a professional Windows 11 image preparation tool built with
native C# and WPF using .NET 8. It enables IT professionals and power users
to create customized Windows 11 installation media with integrated drivers,
removed unwanted apps, unattended installation, and bootable USB creation.

================================================================================
VERSION 5.0.9 - NEW IN THIS RELEASE
================================================================================

🛡️ DEFERRED UPDATES DURING OPERATIONS (SAFETY IMPROVEMENT):

  * NEW intelligent update deferral system prevents mid-operation shutdowns
  * Updates now detect if an operation is currently running
  * If processing (driver injection, image prep, USB creation), update is deferred
  * User is prompted: "Would you like to be notified when operation completes?"
  * After operation finishes, pending update prompt appears automatically
  * Prevents data loss from interrupted long-running operations
  * Ensures safe completion of image preparation and USB creation tasks
  * Works for both manual update checks and first-run update checks

🎯 USE CASE:

  You're in the middle of a 30-minute driver injection process when you check
  for updates. Version 5.0.9 is available, but instead of shutting down
  immediately (and losing all progress), WinImagePrep asks if you want to be
  reminded after the operation completes. Once your image is ready, you'll
  see the update prompt automatically—no lost work, no interruptions.

🔧 TECHNICAL IMPLEMENTATION:

  * Added PendingUpdate and PendingUpdateVersion properties to MainViewModel
  * New CheckPendingUpdateAsync() method for post-operation update prompts
  * CheckForUpdatesAsync() now checks IsProcessing flag before applying updates
  * PerformFirstRunUpdateCheckAsync() silently defers first-run checks if busy
  * Wired CheckPendingUpdateAsync() into all operation completion points:
    - InjectDriversAsync (2 completion points: after injection, after cleanup)
    - CreateUsbFromIsoAsync (finally block)
    - CreateUsbAsync (finally block)

VERSION 5.0.8 - FIRST-RUN UPDATE CHECK
================================================================================

🎉 FIRST-RUN UPDATE CHECK:

  * NEW automatic version check on initial startup
  * Alerts users immediately if a newer version is available
  * Shows comparison: current version vs. latest available version
  * User-friendly dialog with "Update Now" or "Later" options
  * Displays estimated update time (~1 minute depending on download speed)
  * Only checks once per installation - won't nag on every startup
  * Silently skips if already running the latest version
  * Perfect for users who download older published versions

🎯 USE CASE:

  You download WinImagePrep v5.0.6 from the GitHub releases page, but v5.0.8
  is now available. On first launch, WinImagePrep detects this and offers
  to update immediately, ensuring you always start with the latest features
  and fixes. Choose "Update Now" for automatic upgrade, or "Later" to
  use the current version (you can always update from Tools > Check for Updates).

🔧 TECHNICAL IMPLEMENTATION:

  * Added FirstRunUpdateCheckComplete flag to AppSettings
  * New PerformFirstRunUpdateCheckAsync() method in MainViewModel
  * Integrated into MainWindow_Loaded event (after cleanup)
  * Settings automatically persist check-complete status
  * Non-blocking, async operation with graceful error handling

VERSION 5.0.3 - RECENT IMPROVEMENTS
================================================================================

DYNAMIC APP DISCOVERY FROM ISO:

  * NEW "Load Apps from ISO" feature scans install.wim for actual provisioned apps
  * Discovers all ~47 apps present in the Windows image (not just a hardcoded list)
  * Handles variant package names correctly (e.g., MSTeams vs MicrosoftTeams)
  * Works with all Windows 11 editions and builds
  * Full package name resolution for reliable app removal

AUTOMATED WORKFLOW IMPROVEMENTS:

  * Intelligent auto-prompt: When "Remove Windows apps" is checked and you click
    "Prepare Image with Drivers", the app now automatically offers to:
    - Scan the ISO and load all apps
    - Open the app selection dialog
    - Guide you through the removal process
  * No more manual steps - just check the box and go!
  * Graceful fallback to default app list if ISO scanning fails
  * Smart detection of whether apps have already been loaded

APP REMOVAL ENHANCEMENTS:

  * Created ProvisionedApp model with DisplayName, PackageName, Version, PublisherId
  * New GetProvisionedAppsDetailedAsync() method for comprehensive app metadata
  * Dual-mode removal logic:
    - Full package names (from ISO scan) used directly - faster, no re-scanning
    - Partial names (legacy hardcoded list) trigger pattern matching
  * Backward compatible with existing configurations

USER EXPERIENCE:

  * Green "Load Apps from ISO" button for manual discovery
  * Automatic prompts guide users through the process
  * Clear messaging about app loading status
  * Option to continue without app removal if no apps selected

SYSTEM REQUIREMENTS
================================================================================

  Operating System:  Windows 10 version 1809 or later, Windows 11
  Privileges:        Administrator rights required for DISM and USB operations
  Disk Space:        25 GB minimum free space on working drive
  Memory:            4 GB RAM recommended
  .NET Runtime:      Bundled with standalone EXE (no separate install needed)

================================================================================
KNOWN LIMITATIONS
================================================================================

  * Some operations require administrator privileges and will prompt if needed
  * Processing time for image preparation: 20-60 minutes depending on system
  * USB drive creation permanently erases all data on target drive
  * Network drives and OneDrive-synced folders are not supported for working folder
  * Windows 11 ISO required (Windows 10 not officially supported)
