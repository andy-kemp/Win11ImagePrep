WinImagePrep - Release Notes

Version 4.2.1 - Startup & Settings Improvements
Release Date: January 2025
Publisher: Andy Kemp Consulting Ltd

================================================================================
OVERVIEW
================================================================================

WinImagePrep is a professional Windows 11 image preparation tool built with
native C# and WPF using .NET 8. It enables IT professionals and power users
to create customized Windows 11 installation media with integrated drivers,
removed unwanted apps, and bootable USB creation.

================================================================================
VERSION 4.2.1 - NEW IN THIS RELEASE
================================================================================

STARTUP & FIRST-RUN IMPROVEMENTS:

  * Fixed first-run window display and activation issues
  * Corrected application shutdown mode for proper window lifecycle
  * Improved splash screen timing and window ownership handling
  * Enhanced first-run wizard visibility and user interaction flow

STORAGE & PATH UPDATES:

  * Changed default working folder from C:\Win11ImagePrep to C:\ProgramData\Win11ImagePrep
  * All application data now centralized under C:\ProgramData\Win11ImagePrep
  * Updated documentation to reflect new default storage location
  * Settings and working files in consistent parent directory

RESET & TROUBLESHOOTING:

  * Added "Reset to Defaults" functionality for troubleshooting
  * Settings reset capability to restore first-run experience
  * Better error handling and logging during startup sequence
  * Comprehensive diagnostic messages for startup failures

VERSION 4.0.2 - EARLIER RELEASE
================================================================================

FEATURES:

  * Native C# WPF application built on .NET 8
  * MVVM architecture with clean separation of concerns
  * ISO extraction and validation for Windows 11 installation media
  * Driver MSI extraction with cabinet file support
  * Driver injection into boot.wim and install.wim images
  * Windows edition selection and filtering
  * Windows app removal (Teams, Xbox, OneDrive, etc.)

  * Real-time progress tracking and operation logging

TECHNICAL STACK:

  * .NET 8.0 / WPF desktop application
  * MVVM design pattern with data binding
  * DISM (Deployment Image Servicing and Management) integration
  * Windows PowerShell automation for USB creation
  * Cabinet file extraction for driver MSI packages
  * Async/await for responsive UI during long operations

================================================================================
SYSTEM REQUIREMENTS
================================================================================

  Operating System:  Windows 10 version 1809 or later, Windows 11
  Privileges:        Administrator rights required for DISM and USB operations
  Disk Space:        25 GB minimum free space on working drive
  Memory:            4 GB RAM recommended
  .NET Runtime:      Bundled with standalone EXE (no separate install needed)

================================================================================
KNOWN LIMITATIONS
================================================================================

  * Some operations require administrator privileges and will prompt if needed
  * Processing time for image preparation: 20-60 minutes depending on system
  * USB drive creation permanently erases all data on target drive
  * Network drives and OneDrive-synced folders are not supported for working folder
  * Windows 11 ISO required (Windows 10 not officially supported)
