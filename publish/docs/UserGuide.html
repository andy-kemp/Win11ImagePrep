System Requirements

Before you begin, ensure you have:
  • Windows 10/11 (x64) – Host operating system
  • Administrator privileges – Required for mounting images and creating bootable media
  • 25 GB free disk space – On the working drive (default: C:\ProgramData\Win11ImagePrep)
  • Windows 11 ISO file – Official Windows 11 installation media
  • Driver packages (optional) – MSI files, extracted folders, or ZIP archives
  • USB drive (for bootable media) – 14 GB or larger, will be completely erased
  • .NET 8 Runtime – Included in self-contained builds

Standard Workflow

  1. Select Windows 11 ISO

    Click Browse next to "1. Select Windows ISO" and choose your Windows 11 installation ISO file.

    Optionally click Verify to validate the file structure.

  2. Select Driver Source (Optional)

    Choose the driver source type:

    • MSI File – For Surface or OEM driver packages
    • Folder – For pre-extracted driver folders
    • ZIP File – For compressed driver archives

    Click Browse to select your driver source.

  3. Remove Unwanted Windows Apps (Optional)

    Check the box "Remove Windows apps from image".

    Apps automatically load from GitHub when checked. Click "Select Apps to Remove..." to choose which apps to exclude.

    Use Quick Select presets:

    • Remove Bloatware Only – Keeps useful apps like Calculator, Notepad, Paint
    • Remove All Optional Apps – Removes everything
    • Clear Selection – Deselect all

  4. Configure Unattended Installation (Optional)

    Check "Enable Unattended Installation" and click "Configure Unattended Settings..."

    See the Autopilot Mode and Unattended Installation sections for detailed guidance.

  5. Select Windows Editions (Optional)

    Click Select Editions... to choose which Windows 11 editions to include (Home, Pro, Enterprise, etc.).

    Reducing editions speeds up the process significantly.

  6. Prepare the Image

    Click Prepare Image with Drivers.

    This process typically takes 20-60 minutes depending on your system and options selected.

    Monitor progress in the collapsible operation log at the bottom.

  7. Create Bootable USB (Optional)

    Once preparation is complete, click Refresh to detect USB drives.

    Select a USB drive from the dropdown.

    ⚠ Warning: All data on the selected USB drive will be permanently erased.

    Click Create USB to write the prepared image to your USB drive.

🚀 Autopilot Mode (Enterprise Feature)

What is Autopilot Mode?

A specialized deployment mode for Windows Autopilot-enrolled devices. Unlike standard unattended installation, Autopilot Mode preserves the OOBE experience so your company branding and Autopilot enrollment process remain intact.

When to Use Autopilot Mode

  • ✅ Device is enrolled in Windows Autopilot
  • ✅ Want to preserve company branding during setup
  • ✅ Users will sign in with Azure AD (Entra ID) accounts
  • ✅ Need to reimage/refresh while keeping Autopilot enrollment
  • ✅ Want automated disk setup but preserve OOBE experience

What Autopilot Mode Does

✅ Auto-accepts License

Skips the EULA screen automatically

✅ Auto-partitions Disk

Wipes and creates UEFI partitions

✅ Preserves OOBE

Shows "Let's set things up..." with company logo

✅ Skips Privacy Screens

No location/diagnostics/speech/inking prompts

✅ Wireless Setup Enabled

Allows Azure AD join during OOBE

✅ No Local Accounts

Azure AD accounts only

How to Configure Autopilot Mode

  1. Enable Unattended Installation

    Check "Enable Unattended Installation" in the main window.

  2. Open Configuration Dialog

    Click "Configure Unattended Settings..."

  3. Enable Autopilot Mode

    Check "This device is enrolled in Autopilot" ✅

    Notice how the UI automatically hides irrelevant sections (local admin, computer name, setup experience).

  4. Configure Basic Settings

    • Windows Edition – Leave as auto-detect if multiple editions in ISO
    • UI Language – Select language (default: en-US)
    • Time Zone – Select timezone (default: GMT Standard Time)
    • Disk ID – Usually 0 (first disk)

  5. Save and Proceed

    Click Save and continue with image preparation as normal.

Expected Installation Flow (Autopilot)

  1. Boot from USB drive
  2. Disk automatically wiped and partitioned
  3. Windows files copied (no prompts)
  4. System reboots
  5. OOBE appears with company branding 🏢
  6. User connects to Wi-Fi
  7. Device contacts Azure AD and applies Autopilot profile
  8. User signs in with Azure AD credentials
  9. Apps and policies deployed via Intune
  10. Done! 🎉

⚠ Autopilot Requirements

  • Device must already be enrolled in Azure AD Autopilot
  • Autopilot profile must be configured in Intune
  • Company branding requires Entra ID (Azure AD) tenant configuration
  • Users must have valid Azure AD accounts
  • All data on target disk will be permanently deleted

⚙️ Standard Unattended Installation

When to Use Standard Unattended Mode

  • ✅ NOT an Autopilot device
  • ✅ Want completely silent installation
  • ✅ Need local administrator account
  • ✅ Want to skip all OOBE screens
  • ✅ Want to set a specific computer name

How to Configure Standard Unattended

  1. Enable Unattended Installation

    Check "Enable Unattended Installation" in the main window.

  2. Open Configuration Dialog

    Click "Configure Unattended Settings..."

  3. Keep Autopilot Mode Unchecked

    Leave "This device is enrolled in Autopilot" UNCHECKED ❌

  4. Configure All Settings

    • Windows Edition – Specific edition or auto-detect
    • UI Language – Select language
    • Time Zone – Select timezone
    • Administrator Username – Local admin username
    • Administrator Password – Local admin password
    • Computer Name – Optional (leave blank for random)
    • Disk ID – Usually 0
    • Auto-partition disk – Recommended ✅
    • Hide EULA – Recommended ✅
    • Hide wireless setup – Optional
    • Skip OOBE – Recommended for silent install ✅

  5. Acknowledge Warning

    ⚠ FINAL WARNING: Auto-partitioning will WIPE ALL DATA on the target disk without confirmation during installation!

    Click Yes to confirm you understand the risk.

  6. Save and Proceed

    Click Save and continue with image preparation.

Expected Installation Flow (Standard)

  1. Boot from USB drive
  2. Disk automatically wiped and partitioned
  3. Windows files copied (no prompts)
  4. System reboots
  5. Desktop appears immediately – No OOBE, no setup screens
  6. Local admin automatically logged in
  7. Ready to use or join domain manually

🗑️ Windows App Removal

How It Works

WinImagePrep can remove provisioned Windows apps from the installation image before deployment. Apps are loaded automatically from a GitHub-hosted list when you check "Remove Windows apps from image".

Quick Select Presets

Remove Bloatware Only

Removes social/gaming apps while keeping useful utilities like Calculator, Notepad, Paint, Photos, Snipping Tool.

Remove All Optional Apps

Removes everything including useful utilities. Use for minimal installations.

Clear Selection

Quickly deselect all apps to start fresh.

Common Apps to Remove

  • Microsoft Teams – Often replaced with enterprise version
  • Xbox apps – Gaming-related apps
  • Mail and Calendar – If using Outlook
  • OneDrive – If using network storage
  • Solitaire, Candy Crush – Gaming apps
  • Get Help, Tips – Support apps
💡 Tip: App selections are automatically saved and restored across sessions. Your preferences persist even after closing the application.

📂 Changing Storage Locations

By default, WinImagePrep stores temporary and output files in C:\ProgramData\Win11ImagePrep.

To change this location:

  1. Go to Tools > Options
  2. Update the Working Folder path
  3. Click Validate to ensure the folder is suitable
  4. Click Save to apply changes
  5. Restart the application for changes to take full effect
Storage Requirements: The working folder must be on a local fixed disk with at least 25 GB of free space. Network drives, USB drives, and OneDrive-synced folders are not supported.

Directory Structure

C:\ProgramData\Win11ImagePrep\
├── SavedImages\          # Persistent: Saved prepared images
├── Logs\                 # Persistent: Application logs
├── Config\               # Persistent: Configuration files
└── Temp\                 # Temporary: Auto-cleanup working directory
    ├── Windows11\        # Extracted ISO contents
    ├── Drivers\          # Extracted MSI drivers
    └── Mount\            # WIM mount points

Check the Operation Log

New in v5.0.6: The operation log now has a visible scrollbar and properly collapses without leaving empty space.

Review Log Files

C:\ProgramData\Win11ImagePrep\Logs\WinImagePrep_YYYY-MM-DD.log

(Or your custom working folder if changed)

Cleanup & Repair

If the application crashes or an operation is interrupted:

  1. Click Repair & Cleanup in the main window
  2. This will unmount any stuck WIM images and clean temporary files

Common Issues

Issue Solution
Access Denied Run the application as Administrator
Disk Space Errors Ensure at least 25 GB free on the working drive
USB Creation Fails Close any File Explorer windows viewing the USB drive
Mount Errors Use Repair & Cleanup to unmount stuck images
Autopilot showing privacy screens Update to v5.0.5 or later (registry-based suppression)
Operation log scrollbar missing Update to v5.0.6 or later
Empty space when log collapsed Update to v5.0.6 or later

Autopilot-Specific Troubleshooting

Issue: Autopilot not showing company branding
Cause: SkipOOBE was enabled in older versions
Solution: Use Autopilot Mode (v5.0.5+) - it preserves OOBE automatically
Issue: Installation asks for disk partition selection
Cause: Auto-partition not enabled or answer file not found
Solution: Ensure "Automatically partition and format" is checked and autounattend.xml is in USB root

Safety Warnings

⚠ Important Safety Information

  • USB Drive Formatting: Creating bootable USB media will permanently erase all data on the selected USB drive. Back up any important files before proceeding.
  • Unattended Installation Disk Wipe: When auto-partitioning is enabled, the installation will automatically WIPE ALL DATA on the target disk without any confirmation during installation.
  • Administrator Rights: Many operations require administrator privileges. You will be prompted if elevated permissions are needed.
  • Processing Time: Image preparation can take 30-60 minutes or more. Do not interrupt the process or shut down your computer.
  • Disk Space: Ensure sufficient free disk space (25 GB minimum) before starting operations.
  • Answer File Security: The autounattend.xml file contains configuration in plain text. In Standard Unattended mode, admin passwords are stored in plain text. Consider physical security of deployment media.

User Guide - Quick Start

What WinImagePrep Does

WinImagePrep is a professional tool for creating customized Windows 11 installation media. It allows you to:

  • Extract and validate Windows 11 ISO files
  • Extract drivers from MSI packages, ZIP archives, or folders
  • Inject drivers into Windows installation images
  • Remove unwanted apps (Microsoft Teams, Xbox, OneDrive, etc.)
  • Select Windows editions to include in the final image
  • Create bootable USB drives ready for installation
  • Save customized images for reuse or deployment

Requirements

Before you begin, ensure you have:
  • Administrator privileges – Required for mounting images and creating bootable media
  • 25 GB free disk space – On the working drive (default: C:\ProgramData\Win11ImagePrep)
  • Windows 11 ISO file – Official Windows 11 installation media
  • Driver packages (optional) – MSI files, extracted folders, or ZIP archives
  • USB drive (for bootable media) – 14 GB or larger, will be completely erased

Recommended Workflow

    Click Browse next to "Select Windows ISO" and choose your Windows 11 installation ISO file.

    Optionally click Verify ISO to validate the file structure.

    Choose the driver source type:

    • MSI File – For Surface or OEM driver packages
    • Folder – For pre-extracted driver folders
    • ZIP File – For compressed driver archives

    Click Browse to select your driver source.

  3. Remove Unwanted Windows Apps (Optional)

    Check the box "Remove Windows apps from image".

    NEW in v4.3.0: Click the green "Load Apps from ISO" button to scan your ISO and discover all ~47 provisioned apps actually present in the image. This ensures accurate app names (e.g., MSTeams vs MicrosoftTeams).

    Then click "Select Apps to Remove..." to choose which apps to exclude.

    Automated workflow: If you skip loading apps manually, the tool will automatically prompt you to scan the ISO when you start the preparation process!

    Common choices include Microsoft Teams, Xbox apps, Mail/Calendar, and OneDrive.

  4. Select Windows Editions (Optional)

    Click Select Editions... to choose which Windows 11 editions to include in your final image (Home, Pro, Education, etc.).

  5. Prepare the Image

    Click Prepare Image with Drivers.

    This process typically takes 20-60 minutes depending on your system and options selected.

    Monitor progress in the log window at the bottom of the application.

  6. Create Bootable USB (Optional)

    Once preparation is complete, select a USB drive from the dropdown.

    ⚠ Warning: All data on the selected USB drive will be permanently erased.

    Click Create USB to write the prepared image to your USB drive.
